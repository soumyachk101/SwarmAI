Core Architecture

Engineered for Multi-Agent Supremacy

Local-first architecture that eliminates context loss, orchestrates parallel execution, and guarantees absolute privacy.

Shared Pheromone Memory

All agents read and write to a single project brain (.pheromone). When one agent learns an architectural rule or writes an API, all other agents instantly know.

Parallel Git Worktrees

Lead automatically isolates every task in its own git worktree branch. Multiple CLIs edit code simultaneously without overwriting files or merge deadlocks.

Hybrid Vector & FTS5 Search

Local SQLite FTS5 full-text indexing merged with 384-dimensional dense semantic embeddings via Reciprocal Rank Fusion (RRF). Sub-millisecond context retrieval.

Strategic Lead Modes

Switch between Steward (feature planner & task dispatcher), Forager (autonomous bug hunter), and Stinger (deep security auditor).

Offline Voice Dictation

Built-in Whisper.cpp engine runs 100% locally on your CPU/Metal/Vulkan without sending audio streams to third-party cloud servers. Dictate prompts hands-free.

Tauri v2 & Rust Performance

Under 35MB RAM baseline, instant cold startup, real OS pseudoterminal (PTY) control, and zero bloat compared to traditional Chromium wrappers.
