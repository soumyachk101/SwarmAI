How it Works

One command.
Full swarm, ready.

Swarm AI gives you a complete multi-agent development environment. No config hell, no API setup. Just install and start building.

  • ✓ Install once, works on any project
  • ✓ 10+ AI agents pre-configured
  • ✓ Shared memory across all agents
  • ✓ Git worktrees for parallel work
  • ✓ Voice control with Whisper
Why Swarm AI
Built for the future
of coding
Every feature is designed to make you ship faster, think bigger, and never lose context.
🧠

Shared Project Memory

Pheromone gives every agent the same project context. Switch tools — never lose context.

🎯

Parallel Agents

Lead dispatches multiple agents across git worktrees. Build, review, test — all at once.

🔍

Hybrid Search

SQLite FTS5 + 384-dim embeddings with RRF ranking. Find anything in your project instantly.

🎤

10+ CLI Agents

Claude Code, Codex, Aider, OpenCode, Cursor, Cline, Kiro and more — all in one place.

🎙️

Local Voice Dictation

Whisper.cpp offline speech-to-text. No API calls, no network — fully private voice control.

🛠️

Native Desktop

Built with Tauri v2 + Rust. One binary, full PTY, filesystem, git, and browser control.
