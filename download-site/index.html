Workflow Guide

How Swarm AI Works

A completely new way to write code: from single-prompt bottlenecks to coordinated parallel swarm execution.

1 1-Click Project Binding

Open any existing codebase or initialize a new project. Swarm AI automatically sets up a local .pheromone/ memory bridge and detects your installed CLI tools.

2 Lead Mission Dispatch

Give a high-level goal in the Lead tab (e.g. "Implement Stripe billing with webhook handlers and frontend checkout"). The Lead breaks the goal into parallel tasks without writing code itself.

3 Parallel Git Worktrees

Each worker CLI runs in an isolated ephemeral Git worktree on its own branch. Agents edit files simultaneously without stepping on each other or causing git conflicts.

4 Shared Memory & Synapses

When one agent writes an API contract or makes an architectural decision, it is instantly written to Pheromone vector memory and broadcast down active wire connections.

Quickstart & Installation

Get Swarm AI running locally on your development machine in under 2 minutes.

System Requirements

• macOS: 12.0+ (Apple Silicon or Intel)
• Windows: 10 / 11 (64-bit)
• Linux: Ubuntu 20.04+, Debian 11+, Fedora 36+
• Memory: 8 GB RAM minimum (16 GB recommended for 4+ simultaneous CLIs)

1. Installation via Binary

Download the standalone installer for your platform from the Downloads section above and move it to your Applications folder.

2. Terminal CLI Integration

Swarm AI leverages your existing terminal-installed CLI agents. Make sure you have at least one of the supported CLIs installed:

# Install Claude Code globally npm install -g @anthropic-ai/claude-code # Or OpenAI Codex CLI npm install -g @openai/codex-cli # Or OpenCode npm install -g opencode-ai

Pheromone Shared Memory Engine

How multiple independent AI agents stay aligned without repetitive prompt engineering.

Pheromone is a lightweight, embedded SQLite vector database stored inside your project's .pheromone/ folder. When agents work simultaneously:

1. Architectural Decisions made by the Lead Steward are tagged and indexed.
2. Function Signatures & API Contracts written by backend workers are made instantly retrievable by frontend workers.
3. Context Injection ensures each agent receives relevant shared context through an automatic MCP bridge without polluting standard terminal input.

Git Worktree Isolation

Parallel agent safety through ephemeral git worktrees.

Instead of running all AI bots in the same folder where they overwrite each other's edits, Swarm AI provisions a separate Git worktree for each agent under .swarm/worktrees/<task-id>.

When all agents finish their tasks, the built-in Worktree Merge Studio performs a 3-way clean diff dry-run and allows 1-click merging into your primary branch.

Flow Canvas & Synapse Wires

Visual spatial layout for complex multi-model pipelines.

Connect outputs of one agent to inputs of another by dragging between sockets. Synapse wires feature bidirectional pulse indicators, live token velocity telemetry, and single-click disconnection.

Security & Local-First Guarantees

Zero telemetry tracking, air-gapped support, and local credential safety.

• No Middleman Cloud Proxy: Swarm AI never proxies your code or API keys through our servers. All network calls go directly from your local machine to Anthropic/OpenAI or local Ollama instances.
• Local-First Storage: Project memory, task trees, and logs stay entirely on your disk in SQLite and JSON files.
