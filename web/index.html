Quickstart & Installation

Production setup guide for deploying Swarm AI on macOS, Windows, and Linux workstations with local PTY bridges.

1. Prerequisites

Before launching, ensure your host meets the baseline toolchains:

node -v # Must be v20.0.0 or higher git --version # Git 2.38.0+ for worktree concurrency pnpm -v # Recommended (v9.0.0+)

2. Platform Installation

macOS: Download SwarmAI.dmg, drag to /Applications. If Gatekeeper warns, run: xattr -d com.apple.quarantine /Applications/SwarmAI.app

Windows: Run SwarmAI_Setup.exe, then set PowerShell policy: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

Linux:

sudo dpkg -i SwarmAI.deb sudo apt-get install -f

3. Workspace Initialization

When you select a project directory, Swarm AI automatically:

  1. Creates .pheromone/ with embedded SQLite (memory.db).
  2. Sets up .swarm/worktrees/ and appends to .gitignore.
  3. Scans $PATH for global CLI binaries: claude, codex, opencode, aider, antigravity.
  4. Allocates hardware-accelerated PTY pipes with xterm.js frontends.

MCP Integration & Server Registry

How Swarm AI uses the Model Context Protocol to share tools, memory, and capabilities across all agent sessions.

1. What is MCP?

The Model Context Protocol is an open standard letting AI agents connect to external tools and data sources. Swarm AI ships with built-in MCP server support and auto-registers servers into every CLI agent's configuration.

2. Built-in MCP Servers

PH
Pheromone
Hybrid vector + keyword memory search via pheromone_query.
FS
Filesystem
Scoped project file access within workspace boundaries.
GT
Git
Worktree operations, branch management, diff viewing.
CD
Chrome DevTools
Browser automation via CDP — screenshots, navigation, inspection.

3. Auto-Registration Flow

When you open a project folder, Swarm AI automatically:

  1. Resolves the compiled MCP server binary path via get_pheromone_mcp_path.
  2. Injects the stdio server entry into each CLI agent's MCP config.
  3. Preserves existing MCP servers — never overwrites user-configured tools.
  4. Tracks MCP servers per-project via the workspace toolbox.

4. Custom MCP Servers

Add custom MCP servers through the Settings panel. Each requires:

{ "mcpServers": { "my-server": { "command": "node", "args": ["/path/to/server.js"], "env": { "API_KEY": "your-key" } } } }

Pheromone Shared Memory Engine

Technical specifications for local vector indexing, semantic search, and inter-agent memory synchronization.

1. Memory Architecture

Pheromone eliminates context drift by maintaining an embedded SQLite database with sub-millisecond semantic search. Every architectural decision made by any agent is tagged, indexed, and instantly available to all sibling agents.

2. Hybrid Retrieval Pipeline

Combines FTS5 BM25 keyword search with 384-dim char n-gram vector embeddings, merged via Reciprocal Rank Fusion (k=60), capped by a configurable token budget.

3. Database Schema

CREATE TABLE memories ( id TEXT PRIMARY KEY, project_id TEXT NOT NULL, category TEXT NOT NULL CHECK(category IN ('architecture','decision','rule','plan','fact')), title TEXT NOT NULL, content TEXT NOT NULL, embedding BLOB, source_agent TEXT NOT NULL, confidence REAL DEFAULT 1.0, created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP );

4. Memory Categories

architecture — Core tech decisions. decision — Structural declarations. rule — Coding constraints. plan — Task milestones. fact — Discovered environment states.

Git Worktree Isolation & 3-Way Merge

Deterministic file isolation, branch locking algorithms, and clean 3-way fast-forward merges.

1. The Problem

Concurrent disk writes in a single working tree cause race conditions, partial AST writes, and corrupted files. Swarm AI eliminates this via ephemeral Git worktrees.

2. 6-Stage Lifecycle

3. File Ownership Safety Locks

The Lead Steward creates a file lock table in .swarm/locks.json. If Agent 1 owns src/auth/*, Agent 2 gets read-only access — guaranteeing mathematically zero merge conflicts.

Security, Sandboxing & Air-Gap Compliance

Zero-telemetry architecture, local credential security, and enterprise compliance standards.

1. Zero Cloud Proxy

Swarm AI maintains zero middleman cloud infrastructure. All connections originate directly from your machine to the model provider. Your code, diffs, API keys, and repository files are never uploaded to any Swarm AI server.

2. OS Keychain Vault

API keys encrypted at rest using native security primitives:

  • macOS: Apple Keychain via Security.framework.
  • Windows: Windows Credential Manager (DPAPI).
  • Linux: Secret Service API via libsecret / GNOME Keyring.

3. Secret Scrubbing

The PTY stream filter detects and masks environment secrets, JWT tokens, private keys, and .env variables before rendering in terminal buffers or passing to vector memory.

4. Hardened Environment

Only allowlisted env vars are forwarded to agent processes: ANTHROPIC_*, OPENAI_*, GEMINI_*, AWS_*, GIT_*, HOME, USER, LANG. Blocked: LD_PRELOAD, DYLD_INSERT_LIBRARIES, NODE_OPTIONS, BASH_ENV, PYTHONPATH, GIT_SSH_COMMAND.

Frequently Asked Questions

Common questions about installation, configuration, agents, and troubleshooting.

What is Swarm AI and how is it different?
Swarm AI is a local-first desktop workspace that runs multiple AI coding agents in parallel, each in its own isolated Git worktree. Unlike single-thread chatbots, it coordinates Claude Code, Codex CLI, Aider, and others simultaneously with shared project memory (Pheromone). Your code never leaves your machine.
Is Swarm AI free to use?
Yes! Open source under a personal, non-commercial license. Free for personal projects. Commercial use requires a separate license — contact soumya.chk101@gmail.com.
Do I need API keys?
Swarm AI itself needs no API key — it's a local orchestration layer. The coding agents it runs (Claude Code, Codex, etc.) need their provider keys. These are entered in Settings and stored securely in your OS keychain.
Which AI coding agents are supported?
11+ CLI agents out of the box: Anthropic Claude Code, OpenAI Codex CLI, xAI Grok Code, Google Antigravity CLI, OpenCode (DeepSeek/Ollama), Aider, Cursor CLI, Cline, Kiro CLI, Kilo Code, and Kimi Code. Each gets automatic MCP registration with Pheromone, permission bypass flags, and security-hardened environment variables.
How does Pheromone prevent conflicts?
Two mechanisms: (1) Shared vector memory — every architectural decision is indexed and available to all agents via semantic search. (2) File-ownership locks — Lead assigns exclusive write paths to each worker, preventing simultaneous edits.
Can I run on an air-gapped machine?
Yes. Zero cloud dependency. Use local LLMs via Ollama or vLLM with OpenCode. All memory stays on your machine. The only network calls are direct connections to your chosen model provider.
What are the system requirements?
All: Node.js ≥ 20, Git ≥ 2.38, one coding CLI.
macOS: Xcode CLI Tools. Apple Silicon or Intel.
Windows: WebView2 runtime, VS C++ build tools.
Linux: webkit2gtk, libssl-dev, build-essential, libayatana-appindicator3-dev, librsvg2-dev.
How do I build from source?
pnpm install && pnpm turbo build — then cd swarm && pnpm tauri:dev for development. Production: cd swarm && pnpm tauri:build. Always run pnpm turbo build first — Tauri expects prebuilt dist/ artifacts.
User Guide

How to Use Swarm AI

A step-by-step walkthrough from first launch to running your first multi-agent mission.

1
Install & Launch
Download the package for your platform from the Downloads section above. Install and launch Swarm AI. On first launch, you'll see the empty workspace with the Lead dock on the right.
2
Open a Project
Click the workspace selector and choose your project folder. Swarm AI automatically creates .pheromone/ for shared memory, sets up .swarm/worktrees/, and scans your $PATH for installed coding CLIs.
3
Configure Your Agents
Open Settings and add your API keys (stored in OS keychain). Ensure your preferred CLI agents are installed: npm install -g @anthropic-ai/claude-code for Claude Code, etc. Swarm AI auto-detects them on your PATH.
4
Launch Agent Panes
From the Agents plane, click "+" to add a new pane. Select your CLI agent (Claude Code, Codex, Aider, etc.). Each agent gets a real PTY terminal with MCP auto-registration and context injection from Pheromone.
5
Dispatch a Mission via Lead
Type a goal into the Lead dock (e.g. "Add Stripe checkout with webhooks"). Lead queries Pheromone for project context, breaks the goal into tasks with owns, reads, dependsOn, and shows you draft cards for approval before dispatching.
6
Watch Parallel Execution
SwarmMind creates isolated Git worktrees for each task and launches agents simultaneously. Watch real-time output in each terminal pane. Pheromone broadcasts architectural decisions so agents stay synchronized.
7
Review & Merge
Completed tasks appear in the Review column. SwarmMind runs a 3-way merge-tree dry-run to check for conflicts. On your approval, it fast-forward merges clean branches into main and cleans up worktrees.
8
Persist & Iterate
After each session, Pheromone logs agent transcripts, decisions, and findings to .pheromone/memory/. On your next session, relevant context is automatically injected — your project intelligence compounds over time.
