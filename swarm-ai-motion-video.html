Embedding Dims

Swarm AI is a local-first, AI-native desktop development environment. Run any CLI coding agent inside live terminal panes. Every agent reads and writes a shared, project-scoped memory store called Pheromone.

Hand a goal to Lead, and a team of agents builds it in parallel — each in its own git worktree, coordinated by file-ownership locks and the SwarmMind orchestrator.

Deep Dive

Built for how
real teams ship.

🧠

Pheromone — Project Memory Engine

A hybrid retrieval system combining SQLite + FTS5 full-text search with 384-dim character n-gram embeddings. No external APIs, no network calls. Every agent sees the same context.

// Pheromone remembers everything
const memory = await pheromone.query({
  q: "auth flow architecture",
  mode: "hybrid"
});
// → 12 memories, ranked by relevance
⚡

SwarmMind Orchestrator

Automated dispatch, merge, and tracking. Agents work in parallel on isolated git worktrees.

🎯

Lead AI Planner

3 planning modes that break goals into tasks and dispatch agents automatically.

🔀

Git Worktrees

Every agent gets its own branch. File-ownership locks prevent conflicts. Merge when ready.
